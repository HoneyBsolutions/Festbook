FESTBOOK - Function & Event Expense Manager
Powered by HoneyB Solutions

FIRST USE
1. Keep every file in this folder together.
2. For a quick desktop test, open index.html in Chrome or Edge.
3. For full offline installation, host this folder on any HTTPS static host
   (the same method used for HoneyB Nectar), open it once, then choose Install.

DATA & BACKUP
- All records are stored only on the device in the browser database.
- Devices do not synchronise automatically.
- Use Settings > Download Backup regularly.
- Restore accepts a FestBook JSON backup made by the app.
